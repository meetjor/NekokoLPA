# QianLesim 1.1.5 · 卡片排序与浏览器更新

版本 **1.1.5 / 410**。保持 `ee.nekoko.nlpa1` 和 Sakura / Community / 9eSIM 三证书集合，可覆盖安装，不需卸载或删除 eSIM。

## 更新内容

- 移除设置中不可操作的“状态同步”说明，自动同步逻辑保持开启。卡片实际同步中、状态未确认等提示仍会显示。
- 配置列表增加“排列顺序”：长按手柄拖动，也可用上下按钮；完成保存，返回取消。每张 eUICC 在本机独立记住顺序，刷新/重启不重置，新增配置放末尾，启用状态变化不打乱顺序。只改变显示，不修改卡内数据。
- 关于页新增“检查更新”，显示新版本与更新说明；点击“浏览器下载 APK”交给外部浏览器，再由用户覆盖安装。
- 启动自动检查可关闭，只提示不自动下载。存活进程内检查至少间隔 24 小时，手动检查随时可用。检查失败会明确提示，可在浏览器打开发布页。
- 更新只识别本仓库已上传完成的三签 ARM64 版本，包含当前使用的预发布渠道，避免误下载上游或其他签名版本。请求不携带 EID、ICCID、激活码等卡信息。

## 验证

本地 TypeScript、25 套件 181 项 Jest 和定向 ESLint 通过。新增版本选择/不可信下载链接/网络失败/超时/排序持久化与列表变动测试；Android 14/15 CI 增加实际拖动、取消与保存、进程重启保持顺序以及更新失败/新版本页面检查。实际构建、签名和发布结论以本版 Actions 为准。

## 真机观察

1. 打开排列顺序，拖动后返回应取消；点击完成后刷新、重启应保留顺序，正常启用切换仍有效。
2. 关于页检查更新；无网络应明确失败，成功时识别正确版本。关闭启动检查后不自动联网检查。
3. 有后续版本时，点下载应打开手机浏览器，不进入内置网页或直接安装；可正常覆盖安装。

排序依赖已读取的 eUICC 身份；卡不可用或身份尚未读到时先刷新。模拟器使用合成数据，不能代替真实卡、外部读卡器或运营商下载回归。G+D 根续期与 deepmerge 补丁维护仍按既有安全记录执行，iOS 不在本轮范围。
