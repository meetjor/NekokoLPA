# QianLesim 1.1.6 · 首页紧凑效果图复刻

版本 **1.1.6 / versionCode 411**。基于已成功发布的 1.1.5 / 410。用户提供 1.1.5 真机截图，认可之后生成的**单屏深色 UI 效果图**，要求仅按这张图调整首页布局，保持品牌与颜色，不做额外视觉设计。

## 具体变更

1. 顶部“隐私 / 刷新 / 设置”由三张大底色卡片改为图标+文字的无底色横排工具栏，以细线分隔。原按钮点击、禁用规则、隐私设置和刷新调用均不变。
2. SIM1 卡槽及蓝牙入口收紧尺寸、间距；有多个可选卡槽时显示小箭头提示。保留原卡槽选择行为与蓝牙 sheet。
3. eUICC 信息卡稍压缩高度与芯片图标，详情点击、省略号菜单、EID、通知、STK 原动作不变。
4. “eSIM 配置 · N / 调整顺序 / 添加”合为**同一行**。中文“排列顺序”更名“调整顺序”，保留 `profile-sort` testID、原排序页面及持久化/取消逻辑。
5. 配置卡轻微缩短上下内边距和运营商图标尺寸，保留国旗、名称、状态指示、独立启用开关、侧滑编辑/删除与安全保护。
6. 复用原深色石墨黑/科技蓝主题与原几何 App 图标，不增加统计模块、流量数据或新功能。

## 修改文件与边界

仅变更以下表现层：`src/features/main/MainScreen.tsx`、`components/ActionButtons.tsx`、`components/SlotTabs.tsx`、`ProfileCardHeader.tsx`、`ProfileSelector.tsx`、`ProfileRow.tsx` 和 `src/i18n/zh/main.json`。另外按仓库交接规范更新 `package.json`、`AGENTS.md`、`README.md`、`docs/QianLesim-maintenance.md` 与本文件。

**未改动** `src/lpa/**`、`src/store/**`、`android/**`、`src/features/main/ProfileOrderScreen.tsx`、签名脚本、下载、通知、升级和任何 OMAPI 业务逻辑。保留包名 `ee.nekoko.nlpa1` 与 Sakura / Community / 9eSIM 三证书签名集合。

## 验收与接手

构建需要现有 Actions 执行 TypeScript、Jest、12 项原生单测、ARM64 编译、签名证书指纹核对、Android 14/15 模拟器截图、来源证明和 Release。提交本文件不能代表已构建或已真机测试。

真机重点检查：顶部工具栏不再是三张大卡片、排序按钮与添加同排、eUICC 卡和配置卡比 1.1.5 更紧凑；排序、添加、刷卡、启用开关、点击详情和侧滑删除仍正常。字体放大/小屏可能因实际像素宽度而自动调整；若与效果图不同，以真机截图为依据做定向修正，禁止任意改变原布局目标。

**Work 交接特别说明：** 本版针对 2026-11-14 对话中的最后一张深色单屏效果图，视觉元素顺序为品牌头 → 无底色三工具按钮 → SIM1/蓝牙 → eUICC 摘要 → 单行配置标题+调整顺序+添加 → 三张独立开关的运营商卡。不要重新恢复大按钮、把“调整顺序”放回单独一行，或新建全局“切换”功能。
