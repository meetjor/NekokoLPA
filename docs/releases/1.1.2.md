# QianLesim 1.1.2 · 通知显示与七项问题复核

版本 1.1.2 / versionCode 407。保留现有极简界面、每卡独立开关、`ee.nekoko.nlpa1` 包名及 Sakura / Community / 9eSIM 三证书集合。

## 本版改动

- 通知页移除透明内容下的滑动操作底层，改为完整卡片；名称、操作类型、序号、ICCID、按钮独立排列。长名称最多两行，ICCID 可换行，服务器与数量分行；正常和大字体都保留按钮空间。
- 补齐通知页中文说明、待处理数量、操作标签和按钮。每条保留“发送”和“发送并移除”，移除前说明先投递成功才移除通知，**不删除 eSIM 配置**。
- 批量通知显示真实成功/失败/保留数量并保留页面结果。单条区分发送失败、已发送但移除未确认、已移除但列表刷新失败，避免误导重复发送；读卡器消失后禁用操作。
- 修正 1.1.1 外接读卡器遗漏：USB/BLE 构造时默认 available=false 不能被当作“无需连接”；必须先连接初始化。重新扫描同一 BLE id 的新传输对象会释放旧 adapter/session，创建新实例；手动重连通过 Adapter 更新连接状态。
- 下载成功与后续同步结果继续分离，提取实际页面调用路径并补回归。失败通知不会遮住已安装结果。
- 下载进度页补隐私遮罩，进一步移除 JS 传输异常/响应原值日志；昵称编辑框使用原始草稿，避免遮罩字符被误写入卡片，普通详情展示继续脱敏。
- 首页无设备错误提示增加左右留白。

## 验证记录

提交前 TypeScript、改动文件 ESLint、21 个 Jest 套件共 162 项测试通过。Android 构建、原生 9 项测试、最终验签、模拟器截图及发布状态须以本次 Actions 实际结果为准，收尾后登记维护记录。

模拟器检查使用 `.invalid` 服务器与合成卡标识，覆盖深浅色、1.3 倍字体、长名称/长服务器、单条失败与全部投递失败；注入只发生在 ARM64 正式 APK 已签名上传后的 x86_64 检查构建，**发布包不含测试入口或模拟设备**。它不能证明真实运营商、USB/BLE 或 OMAPI 硬件兼容。

## 手机回归

1. 直接覆盖安装，检查原有配置可读取，双向切换后 Loading 正常结束、状态自动更新，无须卸载或删除配置。
2. 通知页检查深浅色：不再有红绿底层穿透，名称/编号不与按钮重叠，中文标签完整。开启大字体与隐私模式再检查。
3. 首页/详情的停用保护应一致；正常启用另一配置仍可用。
4. 若有 USB/BLE 读卡器，再检查初次连接、断开重连、同设备重新扫描和顶部刷新。
5. 真实运营商下载只在有正常需求时验证；安装成功后的同步失败不应要求重新下载安装。发送/移除通知属于实际运营商操作，按正常使用需要进行，不为测试删除 eSIM。
