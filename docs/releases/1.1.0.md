# QianLesim 1.1.0 · 极简科技风

- 首页改为设备选择、设备摘要和 eSIM 配置列表；每张配置保留独立开关，不增加全局切换步骤。
- 石墨黑 / 深蓝灰主题、科技蓝强调色，移除星空、山脉、发光轨道与重阴影。浅色主题同步适配。
- 新几何 eSIM 图标，覆盖 Android 自适应图标、单色图标及常规密度资源。
- 设置和设备详情按实际信息分组；保留添加配置、重命名、标签、删除确认、EID 复制、通知管理、STK、蓝牙 / USB 读卡器等现有流程。
- 移除统计页面、路由及其收藏统计写入。未删除设备上的 eSIM，也不清除用户历史存储。
- LPA、OMAPI、Redux 切换实现及现有安全保护逻辑保持不变；1.0.1 用户确认修复的切换行为作为回归基线。

## 安装与验证

Android ARM64，包名 `ee.nekoko.nlpa1`，versionCode 405。沿用 Sakura、Community、9eSIM 三证书集合，请覆盖安装。发布附带签名校验日志和 SHA-256 文件。

本版本为预发布测试版。TypeScript、单元测试、APK 编译/签名验证与 Android 模拟器页面检查属于自动化验证；模拟器没有真实 eUICC，不能证明读卡、启用/停用或运营商网络行为已通过真机测试。

更新后请确认：可读取现有配置；双向切换后无需下拉刷新即可显示正确状态；设置、添加配置入口正常；桌面图标、长配置名和字体放大下布局正常。不要为了测试删除 eSIM。
