# QianLesim 1.1.4 · 依赖与发布安全加固

版本 1.1.4 / versionCode 409，包名 `ee.nekoko.nlpa1`，沿用 Sakura / Community / 9eSIM 三签。保留每卡独立开关和既有极简 UI，本版不修改 iOS TLS 实现。

## 改动

- 更新有安全公告的 JS 依赖；BLE 3.5.1 去掉不需要的 Expo 工具链。针对尚无上游版本的 deepmerge 加入原型投毒修复及完整性/行为校验；npm 与 Android Maven 依赖扫描纳入发布关卡。
- Actions 固定完整提交 SHA，构建保持只读；正式 APK 增加可核验的 GitHub/Sigstore 构建来源证明，三签及版本校验继续保留。
- LPA 命令返回值、认证结果与下载页面参数增加明确类型，补中文与插值检查；Android 12+ 蓝牙只请求附近设备权限，旧系统定位仅保留到 API 30，系统文件/相册选择不再声明广泛存储权限。检查最终合并 Manifest，避免库重新带入无上限权限。
- 兼容 RSP 根每次 TLS 握手重新校验有效期，一枚过期根不影响其他有效根或系统可信链；TLS 错误显示可操作的中文提示。构建检查根指纹与到期阈值。

## HTTPS 证书边界

G+D 旧根仍于 **2027-05-10** 到期，上游尚未提供已核验的替换。应用不会跳过证书链或域名验证，也不能为第三方续期。新版解决有效期检查、失效隔离和维护提醒；持续使用旧链的运营商仍须迁移证书。详见 [TLS 信任范围](../security/rsp-tls.md)。

## 验证与真机回归

TypeScript、Jest、依赖扫描、原生 HTTPS 故障、ARM64、三签与 Android 14/15 页面检查以此版本 Actions 报告为准；安全报告另存 artifact。发布 job 只有在前序校验通过及来源证明验证成功后创建 Release。此前用户“真机没啥问题”的反馈属于 1.1.3，不能当作本版验收。

请直接覆盖安装，不卸载、不删除 eSIM：

1. 读卡、双向切换，确认 Loading 结束后状态自动更新。
2. 有蓝牙读卡器时测试扫描、首次授权、连接/重连；Android 12+ 应请求附近设备，不请求定位。Android 11 及以下扫描仍需定位。
3. 用正常需要下载的配置验证二维码/相册选择及 HTTPS 下载，无需为测试购买或删除配置。核对失败提示、安装成功后状态同步。
4. 检查中文设置、下载确认/错误页、深浅色与大字体。
