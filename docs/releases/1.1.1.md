# QianLesim 1.1.1 · 安全与异常恢复

版本 1.1.1 / versionCode 406，包名 `ee.nekoko.nlpa1`。保留 1.1.0 极简界面、每卡独立开关、Sakura / Community / 9eSIM 三证书集合。用户已确认 1.1.0 正常切换；本版主要修复审查发现的异常路径，并非宣称原切换 Bug 复发。

## 改动

- Android HTTPS 恢复证书链、有效期及主机名校验，加入明确来源的生产 RSP 根；拒绝明文和跳转；请求超时、正文读取失败及过大响应有明确结束结果。详见 [信任范围](../security/rsp-tls.md)。
- 首页与详情页共用停用保护，启用目标配置仍走原切换流程；重复点击不会重复提交同一界面操作。
- 安装结果与刷新/通知结果分离：已安装但同步失败仍显示安装成功和同步提醒，提供只重试同步的入口。
- 通知返回实际发送、失败、删除和保留数量，失败通知不会被当作全部成功；保留删除通知的原有规则。
- 顶部刷新现在重新读取已有设备数据，设备发现串行执行；连接幂等，断开后旧任务不能向新实例写状态。同名读卡器重连不再使用旧 dispatcher。
- 刷新失败显示“上次读取数据、当前未确认”，详情页也显示同步状态；移除列表展示时自动修改卡内昵称的副作用。
- 禁止结果不明的写操作自动重发；原生通道异常后失效通道，下次命令重开，JS 只对完整只读事务重试一次。
- 移除原生完整 EID/APDU 日志，详情与下载信息增加隐私遮罩；主动复制/编辑仍使用原始值。
- 配置行使用正常浅比较避免名称/图标更新漏渲染；图标缓存离线失败可重试，后台更新通知已显示的行。
- 清理重复 react-dom 声明，与 React 对齐；发布版本从 package.json 派生，早期拒绝已存在标签，构建权限只读，发布单独授权。

## 验证记录

源码提交前已运行 TypeScript 与新增 Jest 回归。最终测试数、Android 原生测试、APK 编译、签名、模拟器页面和 Release 状态以关联 Actions 的实际结果为准；构建完成后在维护记录中登记。

**本版尚未真机测试。** 无卡模拟器不能证明 OMAPI 权限、SIM REFRESH 或运营商下载兼容。未知私有/测试 CI 服务现在会拒绝连接，不承诺所有运营商下载兼容。

## 手机回归建议

1. 直接覆盖安装，确认版本 1.1.1、保留设置且能读取原有配置，不卸载、不删除 eSIM。
2. 用已有两个配置双向切换：Loading 结束后状态正确，无须下拉；短暂“同步中”后应确认，异常时应显示“未确认”。
3. 比较顶部刷新与下拉刷新；详情页与首页的停用保护一致。无需关闭保护测试停用唯一可用配置。
4. 开启隐私模式，查看首页、详情和下载信息。复制属于主动动作，会复制真实值。
5. 有正常需要下载的新配置时，再验证运营商下载；安装成功后断网造成的通知失败应提示同步未完成，不能要求重复下载。无需为测试购买配置。
6. 若使用 USB/BLE，再验证拔插/重连、读卡与通知重试；不要执行真实删除来验证异常重放。
